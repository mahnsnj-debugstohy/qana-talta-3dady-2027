# 🎓 قناة دفعة تالتة إعدادي 2027

منصة تعليمية Mobile-First جاهزة للتشغيل على Termux.

## أهم المميزات
- تسجيل ودخول الطلاب.
- لوحة طالب عصرية.
- المواد والوحدات والدروس.
- الأدمن يضيف رابط YouTube ويظهر تلقائياً داخل "شرح".
- إضافة اختبارات وأسئلة واختيارات وتصحيح فوري.
- درجات ومحاولات الطالب.
- XP ومستويات وإنجازات.
- شهادات عند تحقيق شروط النجاح.
- إعلانات من لوحة الأدمن.
- لوحة أدمن منفصلة.
- إضافة/تعديل/حذف/إخفاء الدروس والاختبارات.
- قاعدة بيانات JSON محلية بدون SQLite أو native modules، لتكون سهلة على Termux.
- حماية مسارات الأدمن وJWT.
- Responsive للموبايل والكمبيوتر.

## تشغيل Termux

```bash
pkg update -y
pkg install nodejs -y
cd ~/storage/downloads
unzip qana-talta-3dady-2027-termux.zip
cd qana-talta-3dady-2027
npm install
npm start
```

افتح:
http://127.0.0.1:8000

## دخول الأدمن الافتراضي
اسم المستخدم:
admin

كلمة المرور:
123456

غيّر بيانات الأدمن في `.env`/متغيرات البيئة قبل الاستخدام الحقيقي.

## إضافة شرح YouTube
من لوحة الأدمن:
إدارة الدروس → إضافة درس
ثم اكتب رابط YouTube كامل مثل:
https://www.youtube.com/watch?v=VIDEO_ID

وسيتم تحويله تلقائياً إلى مشغل داخل المنصة.

## ملاحظة
المشروع مصمم كبداية قوية قابلة للتطوير إلى PostgreSQL/Cloud Storage/رفع فيديوهات وصور وإشعارات Push عند الحاجة.
